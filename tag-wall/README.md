# Toaster Tag Wall (standalone)

Full-page version of the Home page Tag Wall (spray, fat marker, toast/Cybertruck stamps, glitch brush, download your tag).

- Page: https://therapytoaster.github.io/tt-live/tag-wall/
- `index.html`: standalone page (desktop + touch). Wall code copied from the Home `#ttpw-root` block; the Squarespace fit/dock helpers are removed.
- `arcade-card.js`: ARTcade featured card (same pattern as summer/ and toasty-bros/); inserts under the Toasty Bros card and opens the page in the overlay player.
- `arcade-thumb.jpg`: 1280x720 card thumbnail.
