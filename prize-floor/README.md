# Toasty's Prize Floor

A free, first-person arcade of coin pushers and prize machines from every Toasty game. Walk the floor, drop tokens, and haul prizes back to the counter. Play uses in-game Tokens and Stubs only — no real money, no wallets, no crypto.

Play: https://therapytoaster.github.io/tt-live/prize-floor/

Click to look. WASD walks. Click drops a coin at a machine. C opens the card binder. O toggles graphics quality. Esc releases the mouse.

This folder is the playable v0.2 build for GitHub Pages. It does not include screenshots, tests, or source.
