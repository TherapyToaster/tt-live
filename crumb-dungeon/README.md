# Skullz: Crumb Dungeon

A free, turn-based tile-matching roguelike. Slide a row or column, match four or more tiles, and fight with SkulRz heroes in a cardboard-cutout dungeon. Holders unlock cosmetics and perks only — never pay-to-win. No wallet connect, no signing, no real-money gambling.

Play: https://therapytoaster.github.io/tt-live/crumb-dungeon/

Mouse to slide rows and columns. Space ends your turn. Esc cancels. F toggles effects. M mutes. Jam is fruit jam, never blood.

This folder is the playable build for GitHub Pages. It does not include screenshots, tests, or tools.
