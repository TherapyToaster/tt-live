# Mr. Toasty: Toasty Bros

A free run-and-gun platformer by Coty Lake. Run, stomp and blow up your way across the Toasty universe: rescue caged bros, smash the walls, beat each castle boss and get out before it's TOASTED. Worlds 1-6 are playable; Worlds 7-10 are coming soon.

Play: https://therapytoaster.github.io/tt-live/toasty-bros/

Keyboard: Arrows/WASD move, Z/Space/K jump, X/Shift/J run + fire, C/L special, V/I melee, Down enter pipe, Enter start/pause.
Gamepad: D-pad/left stick, A jump, B run + fire, X special, Y melee, Start.
Phones: turn sideways; touch D-pad on the left, A/B/S/M buttons on the right.

Health: every bro takes 3 hits (the hearts under your name). Toast Armor and the Oven Mitt add an extra hit on top. Pits, the TOASTED! blast and the timer are still instant.

All art, music and sound are original and made in code. No external assets. Jam is grape purple.

This folder is the playable build for GitHub Pages (v0.8.1, Worlds 1-6). It does not include screenshots, tests, or tools.
