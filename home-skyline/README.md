# home-skyline

High-detail futuristic neon city backdrop for the therapytoaster.com Home page (desktop only).
Loaded from the Home MAIN Code block snippet `tt-home-skyline` (jsDelivr pin, GitHub Pages fallback).

- One `#tt-skyline` canvas, z-index 0 (behind `#siteWrapper`, under the floating skulls).
- 3 pre-rendered parallax layers (sky/scanline sun/far, mid towers/haze, near brick/glass towers, fire escapes, water tanks, HVAC, graffiti, caution cards, neon tube signs, wet-street reflections) + 30fps live actors (Cybertruck with headlight beam, holographic toast, rain, embers, steam vents, window flickers, RGB glitch slice).
- Hidden below 1024px. Pauses when tab is hidden. `prefers-reduced-motion`: static frame.
- Official Mr. Toasty logo is composited from `mr-toasty-neon-logo-official.png` (never redrawn).
- Preview / apply tooling lives in `/workspace/home-skyline/`. Preview only until Coty publishes.
